A.B Banquet Hall - static website
=================================
Files: index.html, style.css, script.js, images/, videos/

1. Open script.js and edit the CONFIG block at the top:
   - phone and whatsapp  (REQUIRED - currently placeholders)
   - email (optional)
   - bookedDates (dates to show as unavailable)
2. Add your photos/videos from the hall's Google Maps listing:
   images/hero.jpg  (wide photo for the top of the page)
   images/gallery-1.jpg ... gallery-8.jpg
   videos/tour-1.mp4 (+ images/gallery-4.jpg as its thumbnail)
   Missing files show a placeholder, so the site never looks broken.
3. Double-click index.html to preview. Upload the whole folder to any
   static host (Netlify, GitHub Pages, Cloudflare Pages, Vercel).
